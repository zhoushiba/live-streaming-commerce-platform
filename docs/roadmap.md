# 后续规划（roadmap）

> 本文件记录「已经做完的」「下一步要做的」「明确不做的」，便于面试时说明取舍。

## 1. 已完成（v1.0，本次交付）

| 域 | 内容 |
| --- | --- |
| 直播 | 直播间 CRUD、开播/下播状态机、HLS/HTTP-FLV 双协议播放地址、多清晰度、播放 token、推流信息与主播数据、演示态播放器（Canvas 状态机） |
| 互动 | 弹幕（敏感词拦截/屏蔽词打码/限流 5 条 5 秒/历史回放）、礼物（价目表、余额 CAS 扣款、幂等 requestId、飘屏与榜单） |
| 交易 | 下单（充值/房间会员/点播）、幂等键、15 分钟自动关单、取消、订单列表与详情 |
| 支付 | 三渠道抽象（Mock / 微信 V3 / 支付宝）、下单、回调验签、事务内幂等发货、退款、对账 |
| 权益 | 房间会员 31/366 天顺延、点播永久解锁、退款回收 |
| 用户 | 注册/登录/刷新令牌轮换/登出黑名单、登录失败锁定、JWT + 角色守卫（viewer/anchor/admin） |
| 后台 | 平台指标、用户封禁、强制下播、弹幕下架、订单查询、支付对账 |
| 工程 | 20 张表的建表与索引、SQLite/MySQL 双驱动、6 个 e2e 测试套件 73 个用例、Docker/docker-compose/nginx、6 张真实截图 |

## 2. 短期（1~2 周，面试演示向）

- [ ] 真实推流联调：接入 SRS/nginx-rtmp，把 `STREAM_DEMO_MODE` 关掉后验证 HLS 切片与 FLV 低延迟；
- [ ] 直播间商品橱窗：直播中上架商品、点击弹出商品卡、加购到购物车（当前是「礼物 + 会员」交易形态）；
- [ ] 弹幕 WebSocket 断线重连与离线补拉（现在断线后仅重连，不补历史）；
- [ ] 前端骨架屏与图片懒加载，首屏 LCP 优化；
- [ ] 补充单元测试：`PaymentService.settle`、`OrderService.resolvePrice` 的边界单测（当前以 e2e 覆盖）。

## 3. 中期（1~2 月，工程化向）

- [ ] Redis 缓存与分布式锁：房间热度、弹幕限流、订单幂等键下沉到 Redis（`CacheService` 已预留 driver 切换）；
- [ ] 消息队列：支付成功事件改为 MQ 投递，解耦「发货 / 通知 / 统计」；
- [ ] 分库分表与读写分离：订单、支付流水按用户维度拆分；
- [ ] 可观测性：OpenTelemetry 链路追踪 + Prometheus 指标 + 结构化日志采集；
- [ ] CI/CD：GitHub Actions 跑 lint + typecheck + e2e + 构建镜像并推送。

## 4. 长期（产品化向）

- [ ] 多商户（主播自营店铺）与分账结算；
- [ ] 直播回放自动生成（录制转点播）；
- [ ] 推荐系统：基于观看/购买行为的直播间与点播排序；
- [ ] 移动端：H5 自适应已完成，补充小程序端；
- [ ] 内容安全：接入第三方审核（图片/语音/视频）替代本地词表。

## 5. 已知技术债

| 项 | 影响 | 计划 |
| --- | --- | --- |
| 弹幕敏感词为内置词表 | 覆盖有限 | 中期接第三方审核 |
| 礼物榜单实时查库 | 高并发下压力大 | 中期用 Redis ZSET |
| 房间在线人数为累加计数 | 不会自动衰减 | 中期改为心跳 + 定时清理（`viewerFlushCron` 已预留配置） |
| 对账渠道侧为沙箱模拟数据 | 无法直接用于财务 | 接入真实渠道账单下载 API |
| 前端未做权限细粒度按钮控制 | 越权请求会被后端拦截 | 短期用 `v-if` + 路由 meta 收口 |

## 6. 明确不做

- 不做真实资金清结算（需要支付牌照/商户资质），只做技术链路演示；
- 不内置真实版权视频素材，点播媒体源由部署方自备；
- 不引入微服务拆分（当前单体分层足够，拆分收益低于维护成本）。
